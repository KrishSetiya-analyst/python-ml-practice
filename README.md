# Python & Machine Learning Practice

Smaller practice projects in data analysis and regression.

| Project | What it does | Tech |
| --- | --- | --- |
| [Titanic EDA](EDA_TITANIC%20_DATASET.ipynb) | Exploratory analysis of Titanic passenger survival | Pandas, Matplotlib, Seaborn |
| [Multiple regression](multiple_regression.ipynb) | Predicts house prices from area, bedrooms and age; fills missing values with the median | Pandas, Scikit-learn |
| [House price predictor app](streamlit_spp) | Streamlit app that predicts house price from size using a trained regression model | Scikit-learn, Streamlit, Plotly |

## Run the app
```bash
cd streamlit_spp
pip install -r requirement.txt
streamlit run app1.py
```
